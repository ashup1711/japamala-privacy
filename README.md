# JapaMala Privacy Policy

This folder is ready to publish with GitHub Pages.

Before publishing:

1. The monitored privacy contact is
   `divine.tech.expo@gmail.com`.
2. Create a public GitHub repository named `japamala-privacy`.
3. Push this folder as the repository's `index.html`.
4. Enable GitHub Pages from the default branch and root directory.
5. Enter the resulting HTTPS URL in Google Play Console.

Do not use a localhost or computer-IP URL for the Play listing.
